# Wordings

- Status: Accepted
- Created: 2026-08-16

## Objective

UI 文言の英日表記と動詞を統一する。
`src/lib/i18n/messages.en.ts` と `messages.ja.ts` にエントリを追加・変更するときの判断基準とする。

対象は UI に表示される文言に限る。コード中の識別子、コメント、ドキュメントには適用しない。

## Entities

各エンティティについて、英語表記・日本語表記・その操作に使う動詞を定める。
動詞は原則としてこの表以外のものを使わない。

| エンティティ | 英語 | 日本語 | 主要な動詞 |
| --- | --- | --- | --- |
| コピー関数 | Function | 関数 | 追加 / 編集 / 保存 / 削除 / 並べ替え / 共有 |
| 共有 URL 経由の取り込み | Install | インストール | インストール |
| 関数の一覧 | list | 一覧 | 再読み込み |
| 編集フォーム | editor | 編集フォーム | 開く / 閉じる |
| 編集中の変更内容 | changes | 変更内容 | 破棄 |
| 関数名 | Name | 名前 | 入力 |
| 表示色 | Color | 色 | 選択 |
| URL 条件 | URL Pattern | URL パターン | 一致 |
| 関数のコード | Code | コード | 記述 / 実行 |
| ポップアップ画面 | popup | ポップアップ | 開く / 閉じる |
| 同期ストレージ | sync storage | 同期ストレージ | 保存 |
| 旧形式データの変換 | migration | 移行 | 移行 |
| ギャラリー | Function Gallery | ギャラリー | 探す |

### 動詞の使い分け

紛らわしい組み合わせを明示する。

- **追加** と **インストール** — 新しい関数を一覧に加えるのは「追加」。共有 URL から取り込む専用操作だけを「インストール」とする。
- **破棄** と **削除** — 未保存の編集内容を捨てるのが「破棄」。保存済みの関数を消すのが「削除」。「消去」は使わない。
- **保存** — 永続化する操作は常に「保存」。「セーブ」「登録」は使わない。
- **編集** — 既存の値を変える操作。「変更」は変更された内容を指す名詞としてのみ使う (例: 「変更内容を確認し」)。

## 英語のまま残すもの

この拡張のユーザーは JavaScript を書くため、無理に日本語化すると逆に分かりにくくなるものがある。
次のものは日本語 UI でも英語のままにする。

- **options のセクション見出し** — `Functions` / `Hints` / `Debugging` / `Links` / `Settings` / `Install Function` / `Legacy Functions`。
  見出しはページ内の位置を示す目印であり、英語のほうが走査しやすい。カタログにも入れない。
- **リンク名** — `Function Gallery` / `Chrome Web Store` / `GitHub Repository` など、リンク先自身の名前。
- **他ツールの UI 名** — Chrome DevTools の `Inspect` / `Sources` など。ユーザーが実際に画面上で探す文字列と一致させる。
- **Web API の型名・識別子** — `Document` / `DOMParser` / `render(template, view)` など。
- **ライブラリ名** — `Mustache` など。
- **`sandbox`** — セキュリティ上の実行環境を指す固有の概念として扱う。

逆に、文章中の一般名詞としての function は「関数」とする。日本語の説明文に `Function` を混ぜない。

## 表記のルール

- **句点** — 文末には付けない。ボタン・ラベルだけでなく、説明文とエラー文も同じ (例: `名前を入力してください`、`操作に失敗しました。もう一度お試しください`)。
  1 つの文言が 2 文以上に分かれる場合、文と文の区切りには「。」を使う。
- **記号** — `?` `:` `()` は半角のまま使う。全角の `？` `：` `（）` に置き換えない。
- **三点リーダー** — `...` ではなく `…` を使う (例: `保存中…`)。
- **引用符** — UI 名を文中で引用するときは「」を使う (例: 「Sources」パネル)。
- **英数字の前後** — 半角スペースを入れる (例: `URL を更新`、`関数は 1 つだけ`、`${count} 件の関数`)。
- **依頼形** — ユーザーの操作が必要なときだけ「〜してください」を使う。単なる説明には「〜できます」「〜します」を使う。

## Tests

文言そのものを検証するテストは書かない。
日本語で描画されることの確認は代表的な 1-2 件にとどめ、文字列リテラルではなくカタログのエントリ (`ja.functionList.createNew` など) を参照する。
ラベルを言い換えるたびにテストが落ちる状態を避ける。
